# Everforest for Microsoft Edge

A comfortable & pleasant dark theme for Microsoft Edge, faithful to
[sainnhe/everforest](https://github.com/sainnhe/everforest) (high contrast).

This is the Edge counterpart of the Everforest Reasonix theme already in
`themes/everforest`, built in the same style as the
[dracula/microsoft-edge](https://github.com/dracula/microsoft-edge) repo.

## Install

1. Go to `edge://extensions`.
2. Turn on `Developer mode` on the left menu.
3. Click `Load unpacked` on the top right corner.
4. Select the `dist` folder of this project.
5. Activate the theme in `edge://settings/appearance`, if it wasn't activated automatically.
