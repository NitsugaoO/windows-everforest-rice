# palette —— 19 个角色的色板

[`tokens.yaml`](tokens.yaml) 是这套配置里**唯一的颜色来源**。所有应用主题
（Windhawk / yasb / Everything / Edge / VSCode / Neovim / pi / Clash Party）
都从这 19 个角色渲染出来，没有例外、没有临时调的值。

色值取自 [sainnhe/everforest](https://github.com/sainnhe/everforest) 的
**hard（高对比）档**，只有暗色一套（浅色版已于 2026-09 移除）。

## 名字为什么是中文的「用途」而不是色相

因为同一个用途在不同应用里要同一个颜色，而「绿」这个字在换主题时就失去意义了。
`强调` 现在恰好是绿色，但把它改成蓝色只需要改一个值，19 个产物全部跟着变。

## 怎么改色

本仓库只放成品，**不带渲染器**（上游 `everforest-themes` 的 `generator/` 未公开）。
两条路：

1. **就地改**：直接改各产物里的色值。快，但会和 `tokens.yaml` 脱钩，
   下次从上游导出会被覆盖。
2. **按角色重渲染**：模板里的写法只有三种占位符 ——
   `{{角色名}}`（`#rrggbb`）、`{{角色名_nohash}}`（`rrggbb`）、
   `{{角色名_rgb}}`（`r, g, b`，供 `rgba()` 用）。
   把对应文件的占位符按本表替换，就等于自己做了一遍渲染。

整体调明暗改前 5 个背景角色；换主题色改 `强调 / 正常 / 注意 / 偏高 / 危险`。
